# 连接判断法

> 来源：《围棋》第一册 · 邱百瑞 · 第 9-10 页

## R — 原文

> "棋子的气点有己方的子，那么这两个子就形成一个不可分割的整体，它们各自的气也就共同享有。"
>
> 图五：两个白子已连成一个整体，而两个黑子因不在彼此的气点上，也就是中间并没有棋盘线相连，所以黑子还不能算作一个整体。
>
> 图六：黑 1 这手棋使黑方的子连成一个整体，术语称为"接"。

## I — 方法论骨架

**核心判断：两个（或多个）单元是否构成一个整体，不取决于它们看起来近不近，而取决于它们之间有没有**直接的、结构性的连接**。**

围棋里的"连接"是一个非常严格的概念：
- ✓ 直线相邻（上下左右）→ 算连
- ✗ 斜对角 → **不算连**
- ✗ 靠得很近但中间有空 → 不算连

这背后的本质是：**只有能共享资源（气）的才算一个整体**。斜对角的两个子看起来很近，但它们不能共享气，也不能互相救援，所以是两个独立的个体，各自为战。

迁移到非围棋场景：
- 两个团队如果只是"在同一个公司"但没有直接协作关系 → 不算连
- 两个产品如果只是"同一个品牌"但技术栈、用户群、渠道完全独立 → 不算连
- 两个项目如果只是同一个负责人管但没有资源共享 → 不算连

**"接"的动作**：主动在两个分开的单元之间建立直接连接，让它们变成一个整体。围棋里叫"接"（或"连"），对应现实中的"打通""整合""协同"。

## A1 — 书中案例

| 场景 | 是否连接 | 原因 | 图示 |
|---|---|---|---|
| 中腹两子，左右相邻 | ✓ 连接 | 直线相邻，共享气 | 图三(甲) |
| 边上两子，左右相邻 | ✓ 连接 | 直线相邻，共享气 | 图三(乙) |
| 角上两子，直角相邻 | ✓ 连接 | 直线相邻，共享气 | 图三(丙) |
| 两子斜对角 | ✗ 不连 | 没有棋盘线相连 | 图五（黑子） |
| 两子通过一子连接 | ✓ 连接 | 中间有桥，形成整体 | 图六 |

关键观察：连接 = 共享气 = 共享生存资源。不连接 = 各自为战 = 容易被各个击破。

## A2 — 何时调用

**应调用的场景**：
- 判断两个团队/部门/项目是否真正"一体化"了
- 评估并购/整合后，两边有没有真正连起来
- 分析一个生态系统中，各节点之间是强连接还是弱关联
- 判断"多元化"是真的协同还是只是凑在一起
- 决定要不要主动"接"——在两个分散的单元之间建立直接连接

**不应调用的场景（诱饵）**：
- 纯地理位置远近判断 → 这是空间问题，不是连接判断
- 组织架构图上的汇报关系 → 汇报线不是"共享气"的连接
- 品牌/商标归属 → 法律归属不等于结构性连接

**与相邻 skill 的区分**：
- 与 `go-liberty-position` 的区别：本 skill 判断**是不是一个整体**，气的位置法则判断**整体有多少气**。两者配合：先判断是不是整体，再整体算气。
- 与（待蒸馏）`go-cut-strategy` 的区别：本 skill 是**静态判断**（现在连没连），切断策略是**动态行动**（怎么把对方切断）。

## E — 执行步骤

**三步连接判断：**

1. **找边界** — 明确你要判断的是哪两个（或几个）单元
2. **查连接** — 它们之间有没有**直接的、结构性的、共享资源的**连接？
   - 有共同的输入/输出管道吗？
   - 一个出问题，另一个会立刻受影响吗？
   - 它们共享关键资源（人、技术、客户、数据）吗？
3. **定结论** —
   - 有直接连接 → 一个整体，算气、算风险都要合在一起看
   - 没有直接连接 → 各自独立，风险不共担、收益不共享

**"接"的操作：**

如果判断为"不连"但你希望它们连起来：
1. 找到最短的连接路径（像围棋里下在两个子中间的空位）
2. 建立直接的共享资源机制（共用团队、共用平台、共用数据）
3. 验证：去掉这个连接点，两边会不会各自独立？如果会，说明连接是真的

## B — 边界与盲点

1. **"看起来像一个整体"不等于"真的是一个整体"**。很多组织架构图画得像一个整体，但各部门之间没有实际资源共享，本质上还是各自为战。
2. **连接是双向的**。A 影响 B 且 B 影响 A，才算真连接。如果只有单向影响（如总部管分部但分部不影响总部），那是控制关系，不是连接关系。
3. **作者的盲点**：围棋里的连接是二进制的（连/不连），现实中很多连接是灰度的（有强弱之分）。迁移时需要自己加上"连接强度"的维度。
4. **连接不一定总是好事**。连接让整体更强（气更多、更难被各个击破），但也意味着一损俱损——一个出问题可能拖垮整体。围棋里也有"愚形"的说法，连接方式不对反而浪费子力。
