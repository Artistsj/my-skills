- id: f02
  title: 档案全生命周期管理框架（收管存用）
  type: framework
  source_chapter: 第3部分·产品功能简介
  source_quote: |
    "围绕档案的全生命周期管理，以档案的收、管、存、用为主，展开介绍。"
  summary: |
    将档案管理划分为四个阶段：收集（收）、管理（管）、保存（存）、利用（用），
    形成完整的全生命周期管理闭环。
    收集阶段：接口采集、在线录入、批量导入、看图著录、整理组卷、四性检测
    管理阶段：归档流程、格式转换、鉴定销毁、移交接收、库房管理、统计报表
    保存阶段：版本管理、长期保存、数字防篡改
    利用阶段：检索、借阅、编研、统计
  tags: [framework, lifecycle, archives-management]

- id: f03
  title: 预归档平台方法论
  type: framework
  source_chapter: 第20页·预归档管理
  source_quote: |
    "按照业务场景进行文件划分，从单兵作战向系统作战演进。收集整理前置化：
    对于归档周期较长、自动分类规则不明确的档案，可预先进入预归档库，
    由兼职档案管理员或部门业务人员进行日常维护，保证档案完整性。"
  summary: |
    将档案收集工作前置到业务端，在业务系统和正式档案库之间建立预归档缓冲层。
    三层结构：业务人员产生文件 → 兼职档案员在预归档库预整理 → 专职档案员审核后正式归档
    核心动作：元数据自动转换、档案预整理、档案类型匹配、自动分类、自动组件、自动关联
    价值：从"档案员单兵作战"转向"业务系统+兼职档案员+专职档案员系统作战"
  tags: [framework, pre-archiving, front-loading]

- id: f04
  title: 四性检测框架
  type: framework
  source_chapter: 第28页·四性检测
  source_quote: |
    "按照DA/T70标准设计四性检测方案。主要检测归档文件的真实、完整、安全、可用。
    同时会出具相关的四性检测报告，以保证我们电子文件的合规性。"
  summary: |
    基于DA/T70标准，在电子档案全生命周期的三个关键节点（移交与接收、归档、长期保存）
    执行四个维度的质量检测：
    真实性——电子档案的内容、结构和背景信息与其形成时的原始状况一致
    完整性——电子档案的内容、结构、元数据等要素齐全完整
    安全性——电子档案在存储、传输和使用过程中不被篡改、不丢失
    可用性——电子档案可以被正常检索、浏览、读取和使用
  tags: [framework, quality-control, compliance, digital-archives]

- id: f05
  title: 分级分权权限管理框架
  type: framework
  source_chapter: 第51页·核心亮点·分级分权
  source_quote: |
    "支持集团型组织按照档案不同全宗、门类对权限进行组合，
    可以单独控制每一个菜单和数据权限，授予不同组织、角色的用户对象，进行快速赋权。"
  summary: |
    多维度、精细化的权限控制体系，适用于集团多级组织的档案管理：
    维度一：组织权限（全宗/部门/分部）
    维度二：角色权限（管理员/利用者/兼职档案员）
    维度三：功能权限（菜单/按钮级控制）
    维度四：数据权限（按全宗、门类、密级控制可见范围）
    维度五：流程权限（审批节点权限控制）
    核心方法：先按门类定义权限模板，再关联全宗后授予用户对象
  tags: [framework, permissions, rbac, multi-tenant]

- id: f06
  title: 双套制向单套制过渡框架
  type: framework
  source_chapter: 第6页·助力双套制向单套制管理逐步过渡
  source_quote: |
    "结合电子签章，实现电子文件单轨制、电子档案单套制和双套制的全生命周期管理；
    解决全程业务电子化，档案与业务充分融合，实现电子资源统一领导、集中管理、分级分权、资源共享。"
  summary: |
    从传统纸质+电子双套制逐步过渡到纯电子单套制的三步路径：
    第一步（双套制）：纸质档案数字化加工 + 业务系统电子文件预归档，两套并行
    第二步（逐步过渡）：电子签章+四性检测保障电子档案法律效力，减少纸质依赖
    第三步（单套制）：仅以电子形式归档和管理，符合《电子档案单套管理一般要求》
    支撑要素：电子签名/电子印章、四性检测、标准EEP数据包、可信身份认证
  tags: [framework, transition, digital-transformation, dual-system]

- id: f07
  title: 档案利用控制框架
  type: framework
  source_chapter: 第38-39页·档案借阅+利用控制
  source_quote: |
    "电子借阅可限制其预览、下载、打印权限并配置动态水印，到期自动收回权限；
    原文遮盖：通过借阅流程进行档案的在线审批，系统支持在审批流程中对原文进行
    遮盖处理后生成【借阅副本】。"
  summary: |
    档案利用的多层级权限控制体系，从粗到细分为四层：
    第一层：检索权限——能不能搜到
    第二层：借阅权限——能不能看，需不需要审批
    第三层：操作权限——预览/下载/打印，哪些能操作
    第四层：内容控制——原文遮盖（涂抹/加文本/加图片）、页码范围控制、动态水印
    时间维度：借阅到期自动收回权限
    形式维度：电子借阅 + 实体借阅（自动生成出入库单）
  tags: [framework, access-control, archives-utilization]
