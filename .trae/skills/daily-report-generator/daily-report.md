# 撰写日报

从泛微商机情况梳理 Excel 表中，按"反馈时间"筛选当日项目，自动生成纯文本格式的日报。

## 触发场景

当用户出现以下表述时，立即调用本 Skill：

- "帮我写今天的日报"
- "根据这个写份日报"
- "生成日报" / "写日报"
- "整理一下今天的商机进展"
- 用户提供商机表并要求整理当日工作内容

## 数据源约定

Excel 文件包含以下列（列名需去除前后空格后匹配）：

| 列名 | 说明 |
|------|------|
| 序号 | 项目编号 |
| 客户名称 | 客户公司/联系人名称 |
| 产品名称 | 涉及产品 |
| 金额（万元） | 项目金额 |
| 当前阶段 | 项目所处阶段 |
| 反馈时间 | 最近一次反馈日期（用于筛选） |
| 项目对接情况 | 项目当前进展描述 |
| 下一步计划 | 后续行动安排 |
| 状态 | 项目状态 |

Sheet 约定：
默认读取第一个工作表。若 Excel 有多 sheet，优先寻找名称包含"商机"或"项目"的 sheet。

## 操作步骤

### 第一步：确认数据源

1. 检查用户是否已提供 Excel 文件路径或上传了文件
2. 若未提供，询问用户商机表的存放位置
3. 若用户上传了快捷方式文件（.lnk），需解析出实际文件路径

### 第二步：读取并预处理数据

使用 pandas 读取 Excel 文件：

```python
import pandas as pd
from datetime import datetime

# 读取Excel
df = pd.read_excel(excel_path, sheet_name=0)

# 标准化列名（去除前后空格）
df.columns = df.columns.str.strip()

# 客户名称向下填充（同一客户多个项目时，客户名称只填第一行）
df['客户名称'] = df['客户名称'].ffill()

# 转换反馈时间列为日期类型，兼容多种格式
df['反馈时间'] = pd.to_datetime(df['反馈时间'], errors='coerce')
```

列名容错：
如果核心列名略有差异（如"最近反馈时间"、"更新时间"），需智能识别最接近的列名。

### 第三步：筛选当日数据

```python
# 筛选当日数据
today = datetime.now().date()
today_items = df[df['反馈时间'].dt.date == today].copy()
```

如果用户指定了其他日期（如"昨天的日报"、"19号的日报"），按指定日期筛选。

### 第四步：处理无数据情况

如果当日没有符合条件的项目：
1. 检查是否日期格式问题（如文本格式的日期）
2. 尝试宽松匹配：包含今日日期字符串的行
3. 若确实无数据，告知用户"今日暂无反馈项目"，并询问是否需要查看其他日期

### 第五步：生成日报文本

按序号排序，输出纯文本格式：

```
1、客户名称XXXXX: 项目对接情况XXXXX
2、客户名称XXXXX: 项目对接情况XXXXX
3、客户名称XXXXX: 项目对接情况XXXXX
```

格式规则：
- 序号从 1 开始，使用中文顿号"、"
- 客户名称后接冒号和一个空格
- 内容为"项目对接情况"列的内容
- 每条单独占一行
- 按 Excel 中原有的"序号"列排序，若无序号列则按原始行顺序
- 项目对接情况中包含换行符时，保留换行

### 第六步：输出结果

- 直接在对话中输出生成的日报纯文本
- 确保每条单独一行，格式清晰可直接复制使用
